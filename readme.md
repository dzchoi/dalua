# dalua/daluac

## 1. Overview

`dalua` is a dedicated serial terminal for interacting with the remote Lua REPL running on the `dropalt` firmware keyboard. It allows immediate execution of Lua code typed from your host machine, making it easy to test and debug firmware functionality in real time.
```
$ dalua
Connected to /dev/ttyACM0
Lua 5.3.6  Copyright (C) 1994-2020 Lua.org, PUC-Rio
> print("Hello, World.")
Hello, World.
> fw.printf("5 / 3 == %f\n", 5 / 3)
5 / 3 == 1.666667
18
> 
```

`daluac` is a companion Lua compiler that produces a specialized form of Lua bytecode. The generated bytecode can be downloaded to the keyboard to enable custom keymaps and RGB LED effects.
```
$ daluac class.lua effect.lua lamp.lua keymap.lua export.lua >/tmp/bytecode.bin
```

### 1.1. dalua

```
$ ./dalua -h
Usage: dalua [<tty-device>] [<options>]

Options:
  -d                    stream log messages
  -e '<lua_code>'       execute the inline code remotely
  -f <script-file>      execute the script file remotely
  -h                    display this help message
  -n                    do not reconnect
  - (at the end)        eventually execute REPL remotely
```

- `<tty-device>`
  The serial port that connects to the keyboard (e.g. /dev/ttyACM0 on Linux or COM5 on Windows).  
  This argument is optional - if not specified, `dalua` will automatically search all available serial ports.

- `-d`  
  Print log messages along with the code execution result. Useful for debugging the user code.

- `-e '<lua_code>'`  
  Execute a single line of Lua code remotely, showing only its result. REPL is not started unless `-` appears at the end.
  ```
  ./dalua -e 'fw.system_reset()'  # Reboots the keyboard
  ```

- `-f <script-file>`  
  Execute a Lua script file remotely, showing only its result. REPL is not started unless `-` appears at the end.

- `-h`  
  Display the help message.

- `-n`  
  If the serial connection is lost, terminate the application immediately instead of continuing to try the disconnected port.

- `-` (single dash at the end)  
  Start a REPL session even if `-e` or `-f` is given.

> **Note:**  
> `dalua` uses ANSI escape codes to display colored text. If your terminal does not
> support these codes (for example, Command Prompt on Windows 10), use an alternative
> such as **Windows Terminal** or another ANSI‑compatible terminal emulator.

> **Note:**  
> On Linux, users often encounter a "Permission Denied" error when accessing `/dev/ttyACMx` because they aren't in the `dialout` group. To access serial ports without sudo, you may need to add your user to the `dialout` group:  
`sudo usermod -aG dialout $USER` (Log out and back in for changes to take effect).

### 1.2. daluac

```
$ ./daluac
Usage: daluac <script-file>...
        Compiles the script files (to stdout).
```

`daluac` compiles multiple scripts into a single bytecode. The compilation follows these rules:

- Scripts are compiled in the order they are listed.
- Each script is treated as an anonymous function (i.e., a [chunk](https://www.lua.org/manual/5.3/manual.html#3.3.2)) and composed sequentially.
- Return values of one script are passed as arguments to the next.
- The first script receives the string `"keymap"` as its only argument.
- The final script in the sequence must return a table containing the interface functions (specifically the keymap and indicator lamp drivers).



## 2. Installation

You can simply copy and extract the prebuilt `dalua_linux.zip` or `dalua_win.zip` from [dalua binaries](https://github.com/dzchoi/dalua/releases/tag/dalua-v1.0). Or you can build the applications on your own.

> **Note:**  
> Unlike `dalua_win.zip`, `dalua_linux.zip` does not include the necessary dynamic
> link libraries (libc, libm, and libreadline). These libraries are usually
> already installed in most Linux distributions. If they are missing, you can install
> them manually:
> ```
> # On Debian/Ubuntu:
> $ sudo apt update
> $ sudo apt install libc6 libreadline8
> ```
> ```
> # On Fedora/RHEL/CentOS:
> $ sudo dnf install glibc readline ncurses-libs
> ```



## 3. Building the applications on your own

### 3.1. Requirements
- Build enviroment
  ```
  # On Debian/Ubuntu:
  $ sudo apt update
  $ sudo apt install build-essential
  $ sudo apt install libreadline-dev
  ```

  On Windows, it is recommended to use the MSYS2 environment. After installing MSYS2 from [msys2.org](https://www.msys2.org/), open the MSYS2 **UCRT64** terminal and install the following development toolchain:
  ```
  $ pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
  $ pacman -S zip
  $ pacman -S mingw-w64-ucrt-x86_64-readline
  ```

- Source code is available in the [dalua repository](https://github.com/dzchoi/dalua/tree/dropalt).
  ```
  $ git clone https://github.com/dzchoi/dalua.git
  $ cd dalua
  $ git checkout dropalt
  ```

### 3.2. Building
To build the project, run `make` from the git repo directory:
- Windows: use the MSYS2 **UCRT64** terminal
- Linux: use your system terminal

```
$ make
$ .build/dalua
Connected to /dev/ttyACM0
Lua 5.3.6  Copyright (C) 1994-2020 Lua.org, PUC-Rio
> 
```
